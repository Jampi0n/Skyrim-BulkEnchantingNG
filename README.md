# Description

Allows you to repeat enchantments without having to select the item, enchantment and soul again.

# Build

The project is based on [NG Template](https://github.com/libxse/commonlibsse-ng-template), which contains detailed build information.

# Download

The full mod can be downloaded at [Nexus](https://www.nexusmods.com/skyrimspecialedition/mods/79060).
